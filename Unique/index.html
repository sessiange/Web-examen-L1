Questions de Cours : Réponses

Questions Réponses
1. Donnez la structure de base d'un document HTML5. 
<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <title>Document</title>
</head>
<body>
</body>
</html>
2. À quoi sert la propriété CSS display: flex ? Elle active le mode Flexbox sur un conteneur pour aligner, positionner et distribuer l'espace entre ses éléments enfants facilement.
3. Citez trois balises HTML utilisées dans les formulaires. <form>, <input> et <button>.
4. Que produit le code suivant : <h1 style="color:red;">Bienvenue</h1> ? Il affiche un titre principal de taille importante contenant le texte "Bienvenue" écrit en rouge.
5. Expliquez la différence entre : id et class L'id est unique et cible un seul élément précis dans la page. La class est réutilisable et s'applique à plusieurs éléments à la fois.
6. Quelle propriété CSS permet de : a) changer la couleur du texte ? b) changer la couleur de fond ? a) color
b) background-color
7. À quoi sert l'attribut href dans une balise <a> ? Il définit la destination (l'URL ou le lien) vers laquelle pointe le lien hypertexte.
8. Quelle est la différence entre : une balise bloc (block) et une balise en ligne (inline). Donnez un exemple. Une balise bloc prend toute la largeur et commence sur une nouvelle ligne (ex: <div>). Une balise en ligne ne prend que la largeur de son contenu (ex: <span>).
9. Quel est le rôle des balises suivantes : <html>, <head>, <body> ? <html> est la racine globale ; <head> contient les métadonnées techniques ; <body> contient la partie visuelle et interactive de la page.
10. Définissez les termes suivants : HTML et CSS. HTML sert à structurer le contenu de la page web. CSS sert à appliquer le design, les couleurs et la mise en page.
